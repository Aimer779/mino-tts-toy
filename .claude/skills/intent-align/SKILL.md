# Intent Align: 先对齐，再动手

读取相关文档，复述你的理解，确认目标和边界。不要实现，不要写代码，不要给方案。只做一件事：确保你理解我要什么。

## 触发条件

- 开始一个新功能开发
- 切换到不同的任务模块
- 模型开始说"我来实现..."但还没确认目标
- 用户说"先读文档"、"先理解一下"、"复述一下"

## 标准流程

1. 读取用户指定的文档（或 `harness/spec.md`）
2. 输出你的理解：
   - 总目标是什么
   - 当前阶段要收敛什么
   - 你识别出的边界和约束
   - 你的疑问（如果有的话）
3. 等待用户确认

## 输出格式

```
## 意图对齐

### 我理解的总目标
[一句话]

### 当前阶段目标
[一句话]

### 边界约束
- 不做：[列出]
- 保持：[列出]

### 我的疑问
- [问题 1]
- [问题 2]

等你确认后，我再继续。
```

## 规则

| 场景 | 做法 |
|------|------|
| 用户给了文档路径 | 读那个文档，不要凭记忆 |
| 用户没给文档 | 读 `harness/spec.md`，如果不存在就问用户 |
| 没有疑问 | 要主动提出至少一个边界问题（"XX 部分需要动吗？"） |

## 禁止

- 不要开始写代码
- 不要给出实现方案
- 不要说"我理解了"然后直接干活
- 不要跳过疑问部分

## 后续动作

意图对齐通过后，用户会说"继续"或给出下一步指令。不要自作主张进入实现阶段。
